# UPC 1ASI0730 Course Guides

Step-by-step build guides for the course projects. Each guide is the single file you follow in class, on your own machine, to build that project one feature at a time.

Bookmark this repo once. A new guide lands here as each project is covered, in course order.

## Guides

- [OOP Sample](oop-sample-guide.md): Object-Oriented Programming and Domain-Driven Design in C#, across two bounded contexts (SupplyChain, Procurement) and a shared kernel.

## How to use a guide

Open the guide and follow it top to bottom. Try each step yourself first; the reference code for every file is in a collapsed block right below the step, there if you get stuck or want to check your work. You build your own repo from an empty IDE as you go, following the guide's own `Project Setup` section. There is nothing here to clone and run.
